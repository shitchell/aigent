# Architecture

This directory contains high-level system design documentation describing how components are structured and interact.

## Purpose

Architecture documentation provides:

- **System overviews** — The big picture of component relationships
- **Data flow** — How information moves through the system
- **Component boundaries** — What each part is responsible for
- **Integration points** — Where and how components connect

## Files

| File | Description |
|------|-------------|
| [`high_level.md`](high_level.md) | System overview, component interaction, and class structure |

## When to Reference

- **Starting a new feature** — Understand where it fits in the system
- **Debugging cross-component issues** — Trace data flow between parts
- **Onboarding** — Get oriented to the system structure
- **Reviewing PRs** — Verify changes align with architectural intent
